# MALEBO MVP · Ni Mbaya!

**The game that helps you quit.** **Ni Mbaya!** turns quitting betting, pombe, Fuliza
and 3am scrolling into a game, with **Malebo** keeping you in check. Every
shilling kept from your *anasa* gets a real job: school fees, rent, the chama, sending
money home, a side hustle.

> They gamified your anasa. We gamified your comeback.

**Names:** the app is **Ni Mbaya!** · the mascot is **Malebo** · the vices are
**anasa** (indulgences: "Anasa yako?") · the game is **Shanga**.

### Shanga: the game
You build a real **Kenyan bracelet**, one bead per clean check-in, strung in the
flag's order: **black · white · red · white · green**. Every 7th day in a row earns
the **Ngao**, the Maasai shield charm from the flag. A missed day is a gap: the
streak resets, but **no bead is ever taken away**. The journey is the jewellery:
Day 30 **Bangili** (Certified Discipline) → Day 60 **Bangili mbili** → Day 100
**Mkufu** (Village Elder) → Day 365 **Ushanga wa Shujaa** (Legend of the Republic).
This replaced the old Safari route, Moto the flame and the Mbaya monster.

**Phase 1 = HTML + CSS only.** No JavaScript anywhere. It's a fully designed,
clickable game where nothing is saved yet. Every number is an example.

## Malebo's voice (Kenyan internet humour)

Malebo talks in phrases Kenyans already use online. These are common catchphrases
used in his own lines, not anyone's posts or images:

- **Aki wewe!** → Pressure Friend (replaced *We Mzee!*, which means "old man")
- **Malisaa!** → winning / celebration
- **Driver, nishukishe hapo** → the panic button
- **Umebant** → missed a day, gently
- **Greatness tupu** → perfect-week badge
- **Kumi na nne bora** → Day 14 badge
- **Kabej** → the "say no to one kabej" quest
- **Paste** and **nampigia ananiambia sema** → chama chat, nag notifications
- **Kenyans have decided** (TikTok) → league promotion
- **Ya mwisho kabisaa** (TikTok) → the classic relapse excuse
- **Mara kasongo mara chapati** (TikTok) → Anasa Zako page title
- **Januari ina siku 90** → saving before December

Left out on purpose: *"Bag ni ya nini? Alele mtoto"* (alele is a grade of miraa,
the wrong joke for a quitting app), *"kunywa brufen"*, and political memes.

## Who it's for: everyone, 18+, Gen Z voice

- **No default "bro".** Malebo is a guy; the users aren't all guys. In Settings,
  each person picks what he calls them: their name (default), *Prefer not to say*
  (neutral words only), Rafiki, Boss, Bro or Sis. The app never asks for gender.
- **Neutral words Malebo uses:** rafiki, boss, cuzo, wewe, mbogi/chama, *rada?*,
  *niaje!*, *wueh*, *aki wewe!*. Avoided (gendered): manzi, peng, denge, buda,
  *mzee* call-outs.
- **Gen Z humour:** absurd, ironic, self-roasting ("if I don't laugh I'll cry"):
  *discipline era*, *main character*, *delulu is not the solulu*, *touch grass*,
  *siku zombo*. Used lightly, so it doesn't sound like an uncle trying too hard.
- **18+**, because the app talks about betting and alcohol.

## Psychology rules (from the research)

| Finding | What the app does |
| --- | --- |
| Streaks work through loss aversion, but rigid ones cause guilt and quitting | Streak Bima, a **Pause the game** switch, a **consistency %**, a **Comeback** badge |
| Duolingo's guilt nags work, but about 1 in 3 users find them stressful | **Nag level**: Chill / Normal / Unhinged, plus quiet hours |
| A cute face motivates more than a progress bar | Moto has big eyes and gets "hungry" |
| Humour lowers shame in recovery; shaming backfires | **We roast the anasa, never you** |
| Variable rewards are slot-machine psychology | **No spins, no mystery boxes.** The daily surprise is a joke (*Meme ya leo*), never a prize |
| Motivation lasts with choice, growth and belonging | Tone/nag/name choices, levels and Safari, the chama |
| Some people need more than an app | NACADA's free 24/7 helpline **1192** in the footer, panic page and How it works |

## CSS-only tricks (no JavaScript!)

| What you see | How | Where |
| --- | --- | --- |
| Quest total updates when you tick boxes | CSS **counters** + `:has(input:checked)` | §15, `today.html` |
| Malebo replies to your mood | `:has(#feel-calm:checked)` | §8, `checkIn.html` |
| Savings calculator | answers pre-written, `:has()` shows one | §9, `savings.html` |
| Badge + shop pop-ups | HTML `popover` attribute | §19, `profile.html`, `shop.html` |
| "Hold up" panic screen | `#hold-up` link + `:target` | §10, `panic.html` |
| Daily goal ring | `conic-gradient` | §14 |
| Moto | shapes + one `--size` variable | §17 |
| Shanga bracelet | circles on a `::before` "string" | end of the file |
| Zig-zag Safari path | `nth-child` + `translateX(var(--x))` | §16 |
| League shields, jerseys | `clip-path: polygon(...)` | §18, §20 |
| "How does Ligi work?" | `<details>` + `<summary>` | §18 |
